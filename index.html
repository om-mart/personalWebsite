Personal Projects

Engraving Generator

A Python tool that detects contours in images and converts them into vector paths. Real-time sliders let users fine-tune detection parameters such as thresholds and line thickness, making it useful for creating laser-cut stamps and other designs.

Image Quilter

A Python script that creates an image "quilt" by slicing patches from an image's pixel matrix, randomly shuffling their positions, and stitching them together into a new quilted image.
